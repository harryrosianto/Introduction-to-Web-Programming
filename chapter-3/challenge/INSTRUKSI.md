# Challenge — Chapter 3

Dikerjakan secara mandiri. Solusi tidak disertakan dalam repository ini.

## Ketentuan

1. Gunakan `starter/index.html` dan `starter/style.css` pada folder ini sebagai starting point (berisi kartu biodata dari Praktikum 3 dan daftar skill sederhana).
2. Tambahkan efek `hover` pada kartu biodata (`.card`), misalnya perubahan `box-shadow` menjadi lebih tebal ketika kursor diarahkan ke atas kartu.
3. Buat sebuah class baru bernama `.badge` yang menampilkan skill dalam bentuk label kecil berwarna dengan sudut membulat penuh (pill shape), lalu terapkan pada daftar skill.
4. Ubah daftar skill agar setiap item tampil sejajar secara horizontal (bukan bertumpuk ke bawah) menggunakan properti `display`.
5. Eksperimen dengan minimal tiga kombinasi warna berbeda (format HEX, RGB, dan HSL secara berurutan) pada elemen header, lalu tentukan kombinasi mana yang paling nyaman dipandang.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan challenge chapter 3"
   ```
