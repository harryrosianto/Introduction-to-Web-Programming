# Praktikum 4 — Mempercantik Halaman Profil Mahasiswa (Chapter 2)

**Tujuan:** menerapkan seluruh materi chapter ini secara menyeluruh pada file hasil Chapter 2 (header, tabel, form, footer).

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini — berisi halaman profil mahasiswa lengkap dari Chapter 2 (header, biodata, riwayat pendidikan, kontak) beserta `style.css` kosong.
2. Tambahkan style pada **header dan navigasi**, **tabel**, dan **footer** secara bertahap sesuai `README.md` Chapter 3 (bagian Praktikum 4).
3. Jalankan Live Server setelah setiap penambahan style, amati dampaknya terhadap tampilan.
4. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 4 - Mempercantik Profil Mahasiswa"
   ```

## Checklist

- [ ] Header memiliki warna latar dan teks yang kontras
- [ ] Navigasi tanpa garis bawah default, dengan efek hover
- [ ] Tabel menggunakan `border-collapse` dan warna baris judul yang berbeda
- [ ] Footer senada secara visual dengan header
- [ ] Berhasil dijalankan dengan Live Server
