# Mini Project — Website Profil Pribadi (Versi Bergaya / Styled)

Project ini melanjutkan Mini Project Chapter 2. Struktur HTML tidak diubah, hanya ditambahkan `style.css` untuk mempercantik tampilan.

## Requirements

- [ ] `style.css` terhubung dengan benar ke `index.html` menggunakan External CSS
- [ ] Header memiliki warna latar, warna teks, dan perataan yang menarik
- [ ] Navigasi tampil rapi (tanpa garis bawah default, dengan efek hover)
- [ ] Foto profil memiliki style yang baik (misalnya `border-radius` untuk bentuk lingkaran)
- [ ] Bagian Biodata ditampilkan dalam bentuk card menggunakan Box Model, border, dan bayangan
- [ ] Tabel riwayat pendidikan dan jadwal kuliah tampil rapi dengan `border-collapse`
- [ ] Form kontak memiliki tampilan input dan tombol yang lebih baik dari gaya default browser
- [ ] Footer memiliki gaya visual yang senada dengan header
- [ ] Palet warna konsisten (disarankan tidak lebih dari 3–4 warna utama)
- [ ] Maksimal dua jenis font digunakan pada seluruh halaman

> **Perhatian:** Belum boleh menggunakan Flexbox, CSS Grid, Media Query, maupun JavaScript. Fokus murni pada CSS dasar.
