# Challenge — Chapter 5

Dikerjakan secara mandiri. Solusi tidak disertakan dalam repository ini.

## Ketentuan

1. Buat sebuah array berisi minimal lima nilai ujian mahasiswa, lalu gunakan perulangan `for` untuk menghitung dan menampilkan rata-rata nilai tersebut ke Console.
2. Buat sebuah fungsi bernama `periksaKelulusan` yang menerima satu parameter nilai, mengembalikan (return) teks "Lulus" apabila nilai ≥ 60, dan "Tidak Lulus" apabila kurang dari itu.
3. Buat sebuah object bernama `produk` dengan property `namaProduk`, `harga`, dan `stok`, lalu tuliskan program yang menampilkan pesan "Stok Habis" apabila `stok` bernilai 0, atau menampilkan detail produk apabila `stok` lebih dari 0.
4. Gunakan `prompt()` untuk meminta sebuah kata, lalu gunakan perulangan untuk menampilkan setiap huruf pada kata tersebut satu per satu ke Console (petunjuk: String dapat diakses per karakter menggunakan indeks, mirip Array).
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan challenge chapter 5"
   ```
