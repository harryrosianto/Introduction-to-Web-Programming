# Praktikum 2 — Membuat Program Biodata Mahasiswa Menggunakan Variabel

**Tujuan:** menerapkan variabel dan tipe data dasar.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Pada `script.js`, deklarasikan variabel berikut:
   ```javascript
   const nama = "Nama Lengkap Mahasiswa";
   let umur = 20;
   const jurusan = "Ilmu Komputer";
   let sudahBekerja = false;
   ```
3. Tampilkan seluruh data tersebut ke Console menggunakan `console.log()`.
4. Jalankan Live Server dan periksa hasilnya pada Console.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 2 - Biodata Menggunakan Variabel"
   ```

## Checklist

- [ ] Data yang tidak berubah (nama, jurusan) menggunakan `const`
- [ ] Data yang berpotensi berubah (umur, status bekerja) menggunakan `let`
- [ ] Seluruh data tampil di Console
