# Praktikum 5 — Membuat Daftar Mata Kuliah Menggunakan Array

**Tujuan:** menerapkan array beserta method dasarnya.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Buat array `mataKuliah` berisi minimal 2 mata kuliah.
3. Tambahkan satu mata kuliah baru menggunakan `push()`.
4. Tampilkan jumlah mata kuliah menggunakan `length`.
5. Gunakan perulangan `for` untuk menampilkan daftar bernomor ke Console.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 5 - Array Mata Kuliah"
   ```

## Checklist

- [ ] Array `mataKuliah` berhasil dibuat dan ditambah menggunakan `push()`
- [ ] `length` menampilkan jumlah yang benar
- [ ] Perulangan `for` menampilkan daftar bernomor 1, 2, 3, ...
