# Praktikum 4 — Membuat Program Penentuan Nilai Huruf Menggunakan If Else

**Tujuan:** menerapkan percabangan pada studi kasus penilaian mahasiswa.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Gunakan `prompt()` untuk meminta nilai ujian (0-100), konversi dengan `parseInt()`.
3. Gunakan `if`/`else if`/`else` untuk menentukan nilai huruf:
   - ≥ 85 → A
   - ≥ 70 → B
   - ≥ 55 → C
   - lainnya → D
4. Tampilkan hasil ke Console.
5. Uji dengan beberapa nilai berbeda (misalnya 90, 75, 60, 40).
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 4 - Penentuan Nilai Huruf"
   ```

## Checklist

- [ ] Input dikonversi menggunakan `parseInt()`
- [ ] Percabangan `if`/`else if`/`else` menghasilkan nilai huruf yang tepat untuk setiap rentang
- [ ] Sudah diuji dengan minimal 4 nilai berbeda
