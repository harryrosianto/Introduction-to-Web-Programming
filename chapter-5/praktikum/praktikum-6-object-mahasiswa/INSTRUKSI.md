# Praktikum 6 — Menampilkan Data Mahasiswa Menggunakan Object

**Tujuan:** menerapkan object untuk merepresentasikan data biodata secara terstruktur.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Buat object `mahasiswa` dengan property `nama`, `umur`, `jurusan`, `kampus`.
3. Tampilkan keseluruhan object dan beberapa property spesifik ke Console.
4. Ubah nilai property `umur`, lalu tampilkan kembali.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 6 - Object Mahasiswa"
   ```

## Checklist

- [ ] Object `mahasiswa` berhasil dibuat dengan minimal 4 property
- [ ] Property dapat diakses menggunakan dot notation
- [ ] Property `umur` berhasil diubah dan tampil nilai barunya
