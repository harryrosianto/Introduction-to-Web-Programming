# Praktikum 3 — Membuat Kalkulator Sederhana

**Tujuan:** menerapkan operator aritmatika, input, dan konversi tipe data.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Pada `script.js`, gunakan `prompt()` untuk meminta dua angka, konversi menggunakan `parseFloat()`.
3. Tampilkan hasil penjumlahan, pengurangan, perkalian, dan pembagian ke Console.
4. Jalankan Live Server, masukkan dua angka pada kotak dialog yang muncul.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 3 - Kalkulator Sederhana"
   ```

## Checklist

- [ ] Kedua input dikonversi menggunakan `parseFloat()` sebelum dihitung
- [ ] Hasil penjumlahan, pengurangan, perkalian, pembagian tampil dengan benar (bukan penggabungan teks)
- [ ] Berhasil dijalankan dengan Live Server
