# Challenge — Chapter 4

Dikerjakan secara mandiri. Solusi tidak disertakan dalam repository ini.

## Ketentuan

1. Gunakan `starter/index.html` dan `starter/style.css` pada folder ini sebagai starting point.
2. Tambahkan sebuah **hero section** di bagian paling atas halaman (di bawah navbar), berisi nama dan tagline singkat, menggunakan Flexbox untuk memposisikannya tepat di tengah.
3. Buat sebuah bagian **Portofolio** sederhana menggunakan CSS Grid, menampilkan minimal tiga item, dengan satu item yang dibuat lebih menonjol menggunakan `grid-column` agar melebar dua kolom.
4. Tambahkan tombol **"kembali ke atas"** menggunakan `position: fixed`, diposisikan di pojok kanan bawah layar.
5. Tambahkan satu breakpoint tambahan (misalnya `min-width: 1280px`) yang mengatur agar grid kartu portofolio menjadi 4 kolom pada layar sangat lebar.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan challenge chapter 4"
   ```
