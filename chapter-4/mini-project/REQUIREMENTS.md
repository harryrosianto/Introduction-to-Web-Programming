# Mini Project — Website Profil Pribadi (Versi Responsif)

Project ini melanjutkan Mini Project Chapter 3. Konten yang sudah ada dipertahankan, dengan tambahan Hero Section dan Portofolio, lalu seluruh tata letak dirombak menggunakan Flexbox, CSS Grid, Position, dan Media Query.

## Requirements

- [ ] **Navigation Bar responsif** — logo di kiri, menu di kanan (Flexbox), berubah vertikal pada layar sempit (Media Query)
- [ ] **Hero Section** — nama dan tagline, diposisikan di tengah menggunakan Flexbox
- [ ] **Profil** — foto dan biodata tersusun sejajar pada layar lebar (Flexbox), bertumpuk pada layar sempit
- [ ] **Pendidikan** — tabel riwayat pendidikan (dari Chapter 2 & 3, tidak diubah)
- [ ] **Skill** — grid kartu menggunakan CSS Grid, jumlah kolom menyesuaikan layar
- [ ] **Portofolio sederhana** — minimal tiga item, disusun menggunakan CSS Grid
- [ ] **Contact Form** — form kontak dari Chapter 3, tata letak dirapikan
- [ ] **Footer** — senada secara visual dengan header
- [ ] Minimal satu penerapan `position` selain `static` (misalnya tombol kembali ke atas)
- [ ] Media Query minimal dua breakpoint (tablet, desktop)
- [ ] Teruji baik pada Desktop, Tablet, dan Smartphone (Developer Tools)

> **Perhatian:** Belum boleh menggunakan JavaScript dalam bentuk apa pun. Seluruh perubahan tampilan dicapai murni melalui HTML dan CSS.
