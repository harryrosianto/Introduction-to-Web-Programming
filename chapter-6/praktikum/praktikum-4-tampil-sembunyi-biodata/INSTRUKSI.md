# Praktikum 4 — Menampilkan dan Menyembunyikan Bagian Biodata

**Tujuan:** menggabungkan `addEventListener()` dan `classList.toggle()` pada elemen konten.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini — class `.tersembunyi` sudah disediakan pada `style.css`.
2. Pada `script.js`, pilih tombol dan elemen `#biodata`.
3. Tambahkan `addEventListener("click", ...)` yang meng-*toggle* class `tersembunyi` pada `#biodata`.
4. Jalankan Live Server dan uji tombol tersebut.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 4 - Tampilkan Sembunyikan Biodata"
   ```

## Checklist

- [ ] Bagian Biodata hilang saat tombol diklik pertama kali
- [ ] Bagian Biodata muncul kembali saat tombol diklik kedua kali
- [ ] Tidak ada reload halaman saat tombol diklik
