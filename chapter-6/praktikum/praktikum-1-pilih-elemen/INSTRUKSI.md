# Praktikum 1 — Memilih Elemen dan Mengubah Teks

**Tujuan:** memastikan berbagai method pemilihan elemen dapat digunakan dengan benar.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Pada `script.js`, pilih elemen `<h1>` menggunakan `querySelector()`, lalu ubah isinya menggunakan `textContent`.
3. Pilih seluruh elemen `<p>` menggunakan `querySelectorAll()`, lalu tampilkan jumlahnya ke Console menggunakan `.length`.
4. Jalankan Live Server dan amati perubahan judul serta jumlah paragraf pada Console.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 1 - Memilih Elemen dan Mengubah Teks"
   ```

## Checklist

- [ ] Judul `<h1>` berhasil diubah menggunakan `querySelector()` + `textContent`
- [ ] Jumlah paragraf tampil di Console menggunakan `querySelectorAll()` + `.length`
- [ ] Berhasil dijalankan dengan Live Server
