# Praktikum 2 — Mengubah Warna dan Ukuran Teks Menggunakan JavaScript

**Tujuan:** menerapkan `element.style` untuk mengubah tampilan teks.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini.
2. Pilih elemen judul menggunakan `querySelector()`.
3. Ubah `style.color` dan `style.fontSize` pada elemen tersebut.
4. Jalankan Live Server dan amati perubahan warna serta ukuran teks.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 2 - Warna dan Ukuran Teks"
   ```

## Checklist

- [ ] Warna teks berhasil diubah menggunakan `element.style.color`
- [ ] Ukuran teks berhasil diubah menggunakan `element.style.fontSize`
- [ ] Berhasil dijalankan dengan Live Server
