# Praktikum — Chapter 1

Praktikum dikerjakan secara bertahap bersama dosen atau instruktur di kelas, menggunakan `starter/index.html` pada folder ini.

## Langkah Kerja

1. Buka folder `praktikum/starter/` di Visual Studio Code.
2. Ubah isi tag `<title>` menjadi nama lengkap mahasiswa yang bersangkutan.
3. Ubah isi tag `<h1>` menjadi kalimat perkenalan, contoh:
   ```html
   <h1>Perkenalkan, ini adalah [Nama Mahasiswa]</h1>
   ```
4. Tambahkan satu tag `<p>` baru berisi penjelasan singkat mengenai alasan ketertarikan pada web development.
5. Jalankan file menggunakan Live Server, lalu pastikan tampilan sesuai dengan yang ditulis pada langkah 2–4.
6. Tunjukkan hasilnya kepada dosen atau instruktur sebelum melanjutkan ke bagian berikutnya.
7. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum chapter 1"
   ```

## Checklist

- [ ] `<title>` sudah diubah menjadi nama lengkap
- [ ] `<h1>` berisi kalimat perkenalan
- [ ] Terdapat minimal 1 `<p>` tambahan
- [ ] Berhasil dijalankan dengan Live Server tanpa error
- [ ] Sudah di-commit
