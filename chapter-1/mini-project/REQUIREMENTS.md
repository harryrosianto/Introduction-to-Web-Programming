# Mini Project — Kartu Perkenalan Digital Sederhana

Sebuah halaman HTML sederhana disusun untuk berfungsi sebagai kartu perkenalan digital, memanfaatkan seluruh konsep struktur dasar HTML pada Chapter 1.

## Requirements

- [ ] Struktur dasar HTML lengkap dan benar (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- [ ] Judul halaman (`<title>`) mengikuti format: `Kartu Perkenalan - [Nama Mahasiswa]`
- [ ] Satu `<h1>` berisi nama lengkap
- [ ] Minimal tiga `<p>`, berisi:
  - Asal kampus / kota
  - Hobi
  - Alasan mempelajari web development
- [ ] Berhasil dijalankan menggunakan Live Server tanpa error
- [ ] Sudah di-commit dengan pesan yang jelas

## Struktur File

```
mini-project/
├── REQUIREMENTS.md
└── starter/
    └── index.html   ← starter skeleton
```

## Commit

```bash
git add .
git commit -m "Menyelesaikan mini project chapter 1"
```

> Catatan: Struktur folder ini akan digunakan kembali dan dikembangkan lebih lanjut pada chapter-chapter berikutnya (penambahan CSS, dan seterusnya).
