# Challenge — Chapter 1

Dikerjakan secara mandiri. Solusi tidak disertakan dalam repository ini — gunakan referensi pada modul apabila mengalami kesulitan.

## Ketentuan

1. Gunakan `starter/profil.html` pada folder ini sebagai starting point.
2. Tambahkan judul halaman (`<title>`) sesuai tema yang dipilih.
3. Tambahkan minimal satu `<h1>` dan dua `<p>` yang menceritakan profil diri (nama, asal, dan hobi).
4. Jalankan file menggunakan Live Server, lalu amati apakah tampilan sudah sesuai dengan yang diharapkan.
5. Jelaskan dengan kata-kata sendiri (lisan atau tertulis, di luar repository ini) proses yang terjadi mulai dari `Open with Live Server` ditekan hingga tampilan muncul di browser — sebutkan istilah **client**, **server**, **browser**, dan **HTTP**.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan challenge chapter 1"
   ```
