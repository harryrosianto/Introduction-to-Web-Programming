# Challenge — Chapter 7

Dikerjakan secara mandiri. Solusi tidak disertakan dalam repository ini.

## Ketentuan

1. Gunakan `some()` dan `every()` pada data `students` (starter disediakan) untuk memeriksa: apakah ada mahasiswa semester 6 ke atas (`some()`), dan apakah seluruh mahasiswa berada pada semester genap (`every()`).
2. Tambahkan `findIndex()` pada data `students` untuk menemukan posisi mahasiswa bernama "Siti Amalia", lalu gunakan hasilnya untuk mengubah data pada indeks tersebut.
3. Modifikasi `starter/script.js` agar dapat menampilkan **lebih dari satu** negara sekaligus (misalnya seluruh negara di suatu kawasan), menggunakan `map()` dan `.join("")`.
4. Tambahkan Destructuring untuk mengambil `name`, `capital`, dan `population` langsung dari Object negara, alih-alih mengakses `negara.name`, `negara.capital`, `negara.population` satu per satu.
5. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan challenge chapter 7"
   ```
