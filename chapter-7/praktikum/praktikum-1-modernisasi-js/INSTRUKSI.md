# Praktikum 1 — Mengubah JavaScript Lama Menjadi JavaScript Modern

**Tujuan:** menerapkan `let`/`const`, Arrow Function, dan Template Literal pada kode gaya lama.

## Langkah Kerja

1. Buka `starter/script.js` — berisi kode gaya lama menggunakan `var` dan `function` biasa.
2. Ubah kode tersebut secara bertahap:
   - Ganti `var` menjadi `const` (karena nilainya tidak diubah kembali).
   - Ubah `function tampilkanBio` menjadi Arrow Function.
   - Ubah isi fungsi agar menggunakan Template Literal, menggantikan operator `+`.
3. Jalankan ulang kode menggunakan Node.js (`node script.js`) atau Console browser, pastikan hasilnya tidak berubah.
4. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 1 - Modernisasi JavaScript"
   ```

## Checklist

- [ ] `var` diganti menjadi `const`
- [ ] `function` biasa diubah menjadi Arrow Function
- [ ] Operator `+` diganti dengan Template Literal
- [ ] Output tidak berubah dari sebelumnya
