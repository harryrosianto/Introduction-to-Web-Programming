# Praktikum 2 — Mengolah Array of Objects Menggunakan Array Methods

**Tujuan:** menerapkan `forEach()`, `map()`, `filter()`, dan `find()` pada data mahasiswa.

## Langkah Kerja

1. Buka `starter/script.js` — array `students` sudah disediakan.
2. Gunakan `forEach()` untuk menampilkan nama seluruh mahasiswa ke Console.
3. Gunakan `map()` untuk membuat Array baru berisi nama saja.
4. Gunakan `filter()` untuk mendapatkan mahasiswa jurusan "Ilmu Komputer" saja.
5. Gunakan `find()` untuk mendapatkan mahasiswa bernama "Budi Santoso".
6. Tampilkan seluruh hasil ke Console.
7. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 2 - Array Methods"
   ```

## Checklist

- [ ] `forEach()` menampilkan tiga nama ke Console
- [ ] `map()` menghasilkan Array baru berisi nama saja
- [ ] `filter()` menghasilkan Array berisi mahasiswa Ilmu Komputer
- [ ] `find()` menghasilkan satu Object mahasiswa bernama Budi Santoso
