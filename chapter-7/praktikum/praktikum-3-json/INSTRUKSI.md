# Praktikum 3 — Membuat dan Membaca Data JSON

**Tujuan:** menerapkan `JSON.stringify()` dan `JSON.parse()`.

## Langkah Kerja

1. Buka `starter/script.js` — Object `dataMahasiswa` sudah disediakan.
2. Gunakan `JSON.stringify()` untuk mengonversi Object tersebut menjadi teks JSON.
3. Tampilkan hasilnya beserta `typeof`-nya ke Console.
4. Gunakan `JSON.parse()` untuk mengonversi kembali teks JSON tersebut menjadi Object.
5. Tampilkan hasilnya beserta `typeof`-nya, dan akses salah satu property-nya.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 3 - JSON"
   ```

## Checklist

- [ ] `JSON.stringify()` menghasilkan teks bertipe `"string"`
- [ ] `JSON.parse()` menghasilkan Object bertipe `"object"`
- [ ] Property pada hasil `JSON.parse()` berhasil diakses
