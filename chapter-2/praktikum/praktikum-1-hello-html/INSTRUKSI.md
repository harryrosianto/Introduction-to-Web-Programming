# Praktikum 1 — Membuat Halaman "Hello HTML"

**Tujuan:** memastikan struktur dasar HTML dapat disusun dengan benar.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini di Visual Studio Code.
2. Lengkapi `<title>` pada `starter/index.html` dengan teks "Hello HTML".
3. Tambahkan satu `<h1>` berisi teks "Hello, HTML!".
4. Tambahkan satu `<p>` berisi kalimat perkenalan singkat terhadap HTML.
5. Jalankan menggunakan Live Server dan pastikan judul tab serta isi halaman tampil sesuai.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 1 - Hello HTML"
   ```

## Checklist

- [ ] `<title>` berisi "Hello HTML"
- [ ] `<h1>` berisi "Hello, HTML!"
- [ ] Terdapat `<p>` perkenalan
- [ ] Berhasil dijalankan dengan Live Server
