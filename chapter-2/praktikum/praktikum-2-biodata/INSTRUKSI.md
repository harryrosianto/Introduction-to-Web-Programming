# Praktikum 2 — Membuat Biodata Sederhana

**Tujuan:** menerapkan heading, paragraph, formatting text, dan list.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini di Visual Studio Code.
2. Tambahkan `<h1>` berisi nama lengkap.
3. Tambahkan `<p>` berisi satu paragraf perkenalan diri, dengan sebagian kata ditandai menggunakan `<strong>`.
4. Tambahkan `<h2>Data Diri</h2>`, diikuti `<ul>` berisi data seperti tempat tinggal, program studi, dan angkatan.
5. Jalankan menggunakan Live Server dan periksa hasil tampilan.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 2 - Biodata"
   ```

## Checklist

- [ ] `<h1>` berisi nama lengkap
- [ ] `<p>` perkenalan memuat minimal satu `<strong>`
- [ ] `<h2>Data Diri</h2>` diikuti `<ul>` berisi minimal 3 `<li>`
- [ ] Berhasil dijalankan dengan Live Server
