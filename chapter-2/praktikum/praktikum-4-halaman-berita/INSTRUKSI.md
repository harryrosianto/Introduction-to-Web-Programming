# Praktikum 4 — Membuat Halaman Berita Sederhana

**Tujuan:** menerapkan Semantic HTML secara menyeluruh.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini di Visual Studio Code.
2. Susun halaman menggunakan elemen semantik: `<header>`, `<main>`, `<article>`, dan `<footer>`.
3. Tambahkan judul berita menggunakan `<h2>` di dalam `<article>`.
4. Tambahkan tanggal publikasi menggunakan `<small>`.
5. Jalankan menggunakan Live Server, lalu periksa struktur semantik melalui tab **Elements** pada Developer Tools browser.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 4 - Halaman Berita"
   ```

## Checklist

- [ ] `<header>` berisi judul portal berita
- [ ] `<main>` membungkus `<article>`
- [ ] `<article>` memuat `<h2>`, `<small>` tanggal, dan `<p>` isi berita
- [ ] `<footer>` berisi hak cipta
- [ ] Berhasil dijalankan dengan Live Server
