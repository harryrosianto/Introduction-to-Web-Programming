# Praktikum 3 — Membuat Halaman Profil Mahasiswa

**Tujuan:** menerapkan image, hyperlink, dan table.

## Langkah Kerja

1. Buka folder `starter/` pada praktikum ini di Visual Studio Code. Sebuah gambar placeholder sudah disediakan pada `starter/assets/foto-placeholder.jpg` — dapat diganti dengan foto asli.
2. Tambahkan gambar profil menggunakan `<img>` lengkap dengan atribut `alt`.
3. Tambahkan tabel riwayat pendidikan menggunakan `<table>`.
4. Tambahkan hyperlink menuju email menggunakan `<a href="mailto:...">`.
5. Jalankan menggunakan Live Server dan pastikan gambar tampil serta tabel tersusun rapi.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan praktikum 3 - Profil Mahasiswa"
   ```

## Checklist

- [ ] `<img>` tampil dengan atribut `alt` yang deskriptif
- [ ] `<table>` riwayat pendidikan tersusun dengan `<th>` dan `<td>`
- [ ] Terdapat hyperlink `mailto:`
- [ ] Berhasil dijalankan dengan Live Server
