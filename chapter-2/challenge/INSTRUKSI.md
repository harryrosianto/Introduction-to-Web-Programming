# Challenge — Chapter 2

Dikerjakan secara mandiri. Solusi tidak disertakan dalam repository ini.

## Ketentuan

1. Gunakan `starter/galeri.html` pada folder ini sebagai starting point.
2. Tambahkan minimal tiga gambar menggunakan `<img>`, masing-masing dengan atribut `alt` yang deskriptif.
3. Tambahkan sebuah form sederhana pada halaman yang sama berisi input `text` untuk nama, input `email` untuk alamat email, dan sebuah `<textarea>` untuk pesan, lengkap dengan `<label>` pada setiap input.
4. Tambahkan navigasi (`<nav>`) yang menghubungkan `galeri.html` dengan `mini-project/final/index.html` menggunakan hyperlink relatif.
5. Validasi halaman `galeri.html` menggunakan [W3C Validator](https://validator.w3.org), lalu perbaiki seluruh error yang ditemukan hingga dokumen dinyatakan valid.
6. Commit hasil pekerjaan:
   ```bash
   git add .
   git commit -m "Menyelesaikan challenge chapter 2"
   ```
