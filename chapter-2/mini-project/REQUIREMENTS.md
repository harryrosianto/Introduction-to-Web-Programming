# Mini Project — Website Profil Pribadi

Sebuah website profil pribadi disusun menggunakan HTML murni, memanfaatkan seluruh materi Chapter 2. CSS dan JavaScript belum digunakan pada project ini.

## Requirements

- [ ] `<header>` berisi nama dan navigasi menuju setiap bagian halaman (anchor link)
- [ ] Foto profil menggunakan `<img>` dengan atribut `alt` yang sesuai
- [ ] Bagian **Biodata** (paragraf/list)
- [ ] Bagian **Riwayat Pendidikan** menggunakan `<table>`
- [ ] Bagian **Hobi** menggunakan `<ul>` atau `<ol>`
- [ ] Bagian **Skill** menggunakan `<dl>` (daftar deskripsi) atau list biasa
- [ ] **Tabel Jadwal Kuliah** menggunakan `<table>` dengan `<thead>`, `<tbody>`, dan minimal satu `colspan`/`rowspan`
- [ ] **Form Kontak** dengan input nama, email, pesan — masing-masing dengan `<label>`
- [ ] `<footer>` berisi hak cipta
- [ ] Seluruh konten utama dibungkus elemen semantik (`<main>`, `<section>`, dst.), bukan `<div>`
- [ ] Sudah divalidasi menggunakan [W3C Validator](https://validator.w3.org) hingga bebas error

> **Perhatian:** Tidak boleh menggunakan CSS maupun JavaScript dalam bentuk apa pun pada project ini.
